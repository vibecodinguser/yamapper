Версии ​

Текущая версия расширения — 3.0.0. Обновления приходят автоматически из магазина браузера; проверить установленную версию можно в попапе настроек — внизу показан номер со ссылкой на эту страницу.

Как обновляется расширение ​

  • Chrome и Яндекс.Браузер — через Chrome Web Store, обновление ставится фоново; чтобы применить сразу, нажмите «Обновить» на странице расширений.
  • Firefox — через addons.mozilla.org, обновление проверяется браузером.
  • Ручная установка — архивы и исходники лежат в релизах на GitHub.

После обновления расширения обновите вкладку карты: старые content scripts остаются в уже открытой странице и работают по-старому.

3.0.0 ​

Крупное обновление интерфейса и разрешений.

  • Попап настроек в шапке редактора вместо боковой панели: кнопка-шестерёнка среди нативных кнопок, внутри три вкладки — «Редактор», «Модерация», «Стиль».
  • Необязательные разрешения Яндекса. Пока «Заметки» и «НСПД» выключены, расширение не обращается к Яндексу и не открывает окно входа. Доступ запрашивается по кнопке, а не при установке.
  • Следование теме и языку редактора. Ручные переключатели темы и языка убраны: расширение всегда оформлено и переведено так же, как редактор.
  • Разрез растительности и водоёмов — новая кнопка в нативном тулбаре.
  • Заметки: группы, фильтры по виду/группе/видимости, сортировка, отметка нескольких заметок, оформление (цвет, прозрачность, заливка, узор, подпись), подтверждение удаления как в нативном редакторе.
  • Внешние геосервисы: порядок пунктов меняется перетаскиванием и запоминается; в раздельном виде контролы Nakarte скрыты.
  • НСПД: кнопка «Разрешить доступ» прямо в строке настройки.
  • Наблюдение за объектами: нативная иконка обновления, пауза при ограничении частоты запросов.
  • Автообновление после загрузки — переключатель, который перезагружает карту, когда данные записаны.

2.4.x ​

  • Кнопка «Загрузка из НСПД» включена по умолчанию.
  • Снятие объекта с наблюдения из меню «Ещё», пауза опроса после ответа 429.
  • Счётчик вершин выключен, пока его не включат в настройках.
  • Инструмент разреза: нативные маркеры точек разреза, общий инструмент для растительности и водоёмов.

2.3.x ​

  • Настройки сгруппированы в раскрывающиеся секции; ссылка «Предложить улучшение» вместо старой формы обратной связи.
  • Заметки: редизайн карточки, строка инструментов списка, бейдж количества в группе, адаптивная карточка на всю ширину, подтверждение удаления.
  • Наблюдение за объектами: лента в формате нативной «Мои правки», иконки категорий, вкладка «Мои объекты».

1.4.x ​

  • Фильтр истории правок: выпадающий фильтр по действию, переработанная подгрузка истории по периодам.
  • Синхронизация дат в календаре загрузки и в блокноте.
  • Стили интерфейса синхронизированы со шрифтами Народной карты.
  • Раздельный вид: сохранение параметров и слоёв Nakarte, устранение рассинхронизации центра и зума.
  • Добавлен геосервис ЭтоМесто.

1.3.x ​

  • Синхронизация дат между пикером и блокнотом.
  • Отмена выбора точки в блокноте.
  • Счётчик вершин для линейных объектов.
  • Кнопка фильтра правок выключена по умолчанию.

1.2.x и раньше ​

  • Следование теме редактора для элементов управления.
  • Стабильный id расширения в Chrome.
  • Загрузка точек и первые версии конвертеров.

Формат версий ​

Номер версии — MAJOR.MINOR.PATCH:

  • MAJOR — заметные изменения интерфейса или поведения, которые требуют привыкания (например, переезд настроек из боковой панели в попап).
  • MINOR — новые функции, обратно совместимые.
  • PATCH — исправления без новых функций.

Полная история коммитов — в репозитории.
