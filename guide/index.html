Установка ​

Yamapper — расширение для браузера на Manifest V3. Работает в Chrome, Яндекс.Браузере и Firefox.

Установка из магазина ​

  • Chrome и Яндекс.Браузер — Chrome Web Store → «Установить».
  • Firefox — addons.mozilla.org → «Добавить в Firefox».

После установки откройте редактор Народной карты. Если вкладка была открыта заранее — обновите её, иначе кнопки не появятся.

Требования ​

  • Современный браузер с поддержкой Manifest V3 (Chrome 137+, Firefox 140+).
  • Аккаунт Яндекс ID — расширение сохраняет файлы на ваш Яндекс Диск.
  • Доступ к n.maps.yandex.ru.

Какие разрешения запрашиваются ​

РазрешениеЗачемКогда спрашивается
storageнастройки и сессияпри установке
scripting, tabs, activeTabпанель и content scripts на странице редакторапри установке
n.maps.yandex.ru, nakarte.meработа на карте и раздельный видпри установке
Яндекс Диск и identityБлокнот, заметки, загрузка данныхпри включении «Заметок» или первом входе
nspd.gov.ruзагрузка объектов из НСПДпри включении «Загрузки из НСПД»

Разрешения Яндекса и НСПД — необязательные: пока функции выключены, расширение к этим доменам не обращается. Выключение функции не отзывает уже выданное разрешение — это делается в настройках браузера.

Подробнее о том, что расширение читает и пишет, — в разделе «Приватность» и в README репозитория.

Первые шаги ​

  1. Откройте редактор и найдите кнопку-шестерёнку в шапке — это настройки.
  2. Загрузите первый файл по инструкции «Первая загрузка».
  3. Пройдитесь по разделам справки: Редактор, Модерация, Стиль.

Если что-то не появилось ​

Кнопок нет на карте — смотрите «Кнопки не появились на карте». Остальные ошибки — в разделе «Вопросы и типичные ошибки».
